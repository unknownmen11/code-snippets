# Manager

Internal tooling for managing configs, scripts, and small utilities. This is a grab-bag repo where reusable snippets live before they graduate to dedicated projects.

## Contents

- `src/utils.js` — common helper functions
- `src/config.js` — shared config template
- Config templates
- Draft utilities

## Why this exists

Keeps common patterns in one place instead of scattered across multiple repos. Nothing fancy—just stuff that gets reused.

## Usage

Copy the files you need into your project, or import them as a module if you set this up as a package.
